## Domain glossary

Use these names in code, comments, and UI copy. Do not invent synonyms.

- **Arena** — the React Build Arena at `/` (`src/ui/BuildArenaPage.tsx`). Sparse voxels, protected implicit platform at `y = 0`, first buildable layer `y = 1`.
- **Play Space** — the first-person page at `/MINECRAFT_3D/index.html`. Grass terrain sits at `y = -1`. Redstone simulation lives only here.
- **Catalogue** — the union of placeable block ids. Arena and Play Space must accept the same ids. Visuals differ (Arena = colored meshes; Play Space = PNG / procedural textures).
- **Redstone kit** — the nine Play Space circuit ids added to the Arena catalogue: `redstone_wire`, `redstone_torch`, `redstone_block`, `lever`, `button`, `repeater`, `comparator`, `lamp`, `piston`. Static in the Arena (no signal sim). Repeaters/comparators store `facing` + comparator `mode`.
- **Blueprint** — existing `BlueprintV2` in `src/core/blueprint.ts` (absolute Arena coordinates, `schemaVersion: 2`). Export JSON stays this format.
- **Inventory** — `localStorage` key `build-arena.inventory.v1`. A list of saved builds: relative blocks, `platformSize`, thumbnail. Shared by Arena and Play Space (same origin).
- **Handoff** — one-shot `localStorage` key `build-arena.handoff.v1`. Written just before navigating to the Play Space; Play Space reads and deletes it.
- **Transplant** — map Inventory/Handoff blocks onto Play Space `world.place`. Relative XZ from the click (min-corner). `worldY = arenaY - 1` so Arena `y = 1` sits on the grass.
- **Sandbox** — `MINECRAFT_3D/js/agent.js` `runPlan`. Whitelist + integer coords + max 200 actions. Partial apply (skips bad actions). Fast agent path on the Play Space.
- **Circuit Desk** — Play Space HUD (key **B**). Validated draft + ghosts + player Apply/Discard. Agent tool `propose_world_edit` fills the draft and must not call `runPlan`. Planned in `plans/004-circuit-desk.md`.
